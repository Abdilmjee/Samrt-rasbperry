# نظارة ذكية للمكفوفين (Smart glasses for the blind)

نظرة عامة
---------
مشروع "نظارة ذكية للمكفوفين" يهدف إلى تحسين جودة حياة الأشخاص المكفوفين وتمكينهم من عيش حياة طبيعية ومستقلة. توفر هذه النظارة مجموعة واسعة من الميزات التي تُسهم في اندماجهم الاجتماعي وتعزيز ثقتهم بالنفس من خلال الوظائف التالية:

الوظائف الأساسية
----------------
- قراءة النصوص والتعرّف عليها وترجمتها
  - تحويل النص المكتوب إلى كلام: تمكين المكفوفين من قراءة أي نص مكتوب سواء في كتاب أو مجلة أو حتى إشارة شارع.
  - ترجمة النصوص إلى العربية: تيسير فهم النصوص بلغات مختلفة وتوسيع آفاق المعرفة والتواصل.

- التعرف على الأشخاص
  - تحديد الأشخاص: تستطيع النظارة التعرف على الأشخاص القريبين عبر قاعدة بيانات صور أو صوت.

- التعرف على الأشياء
  - وصف الأشياء: تقديم وصف صوتي للأشياء في البيئة المحيطة مثل الأثاث والأجهزة والأغراض الأخرى.

- معرفة الوقت والتاريخ
  - تزويد المستخدم بمعلومات دقيقة عن الوقت والتاريخ الحاليين.

- التعرف على الألوان ووصفها
  - تحديد الألوان الموجودة في البيئة المحيطة وتقديم وصف صوتي للمستخدم.
  - التعرف على ألوان الملابس لمساعدة المستخدم في اختيار ملابس مناسبة.

- التعرف على العملات
  - تحديد قيمة العملة: تمكين المستخدم من معرفة قيمة العملات الورقية والمعدنية المختلفة مما يساعده على التسوق وإجراء المعاملات النقدية بنفسه.

- تسجيل الملاحظات الصوتية
  - تدوين الملاحظات: إمكانية تسجيل ملاحظات صوتية لتذكر المعلومات المهمة.
  - تذكير المهام: استخدام الملاحظات الصوتية كتذكير للمهام اليومية.

قيمة المشروع
------------
تُقدّم النظارة الذكية وسيلة مساعدة عملية تتيح للمكفوفين الاعتماد على أنفسهم في كثير من الأنشطة اليومية، وتدعم استقلاليتهم، وتقلّل الحواجز الاجتماعية والتواصلية.

التقنيات والمكتبات الأساسية
-----------------------------
- لغة البرمجة: Python 3
- تحويل كلام إلى نص: Vosk
- رؤية حاسوبية: OpenCV (DNN)، face_recognition (dlib)
- تحويل نص إلى كلام: gTTS أو espeak
- OCR: Tesseract (pytesseract)
- تشغيل وتسجيل صوت: sounddevice، scipy، pygame، mpg321/aplay
- دعم العربية: arabic_reshaper، python-bidi
- كاميرا Raspberry Pi: picamera أو picamera2

المتطلبات (Prerequisites)
-------------------------
- جهاز: Raspberry Pi (موصى به Raspberry Pi 3/4 أو أحدث)
- كاميرا Raspberry Pi أو كاميرا USB متوافقة
- ميكروفون وسماعات أو مكبر صوت
- Python 3.7+
- أدوات نظام: git, pip, apt
- برامج نظامية مطلوبة: mpg321 أو مشغل MP3 آخر، tesseract-ocr مع حزمة اللغة العربية (`tesseract-ocr-ara`)
- مكتبات قد تحتاج بناء: dlib (يحتاج أدوات بناء مثل cmake)
- ملفات نماذج كبيرة: ملفات نموذج الكشف (frozen_inference_graph.pb وملف .pbtxt)، نموذج Vosk (موجود كـ model.rar ويجب فكّه إلى مجلد `model/`)

التثبيت والإعداد (مثال على Raspberry Pi OS)
-------------------------------------------
1. تحديث النظام:
   sudo apt update && sudo apt upgrade -y

2. تثبيت متطلبات النظام الأساسية:
   sudo apt install -y python3 python3-venv python3-pip git build-essential cmake libopenjp2-7-dev libtiff5-dev libjpeg-dev libatlas-base-dev libblas-dev liblapack-dev libffi-dev libssl-dev libsndfile1 portaudio19-dev libportaudio2 mpg321 tesseract-ocr tesseract-ocr-ara

3. إنشاء وتفعيل بيئة افتراضية:
   python3 -m venv venv
   source venv/bin/activate

4. تثبيت تبعيات Python:
   pip install --upgrade pip
   pip install numpy scipy opencv-python-headless pillow vosk sounddevice gTTS pygame face_recognition dlib pytesseract arabic_reshaper python-bidi picamera picamera2

   ملاحظات:
   - قد يكون من الأفضل تثبيت `opencv` و `dlib` عبر الحزم النظامية أو بناءها محليًا لتجنّب الأخطاء.
   - gTTS يتطلّب اتصال إنترنت. لاستخدام نطق محلي، استعمل espeak أو pyttsx3.

5. إعداد نموذج Vosk:
   - فكّ ضغط `model.rar` إلى مجلد `model/` في نفس مسار `ad.py` أو ضبط `MODEL_PATH` ليشير إلى مسار النموذج.

6. التأكد من وجود ملفات نموذج الكشف:
   - تأكد من وجود `frozen_inference_graph.pb` و `ssd_mobilenet_v3_large_coco_2020_01_14.pbtxt` و `coco.names` في المجلد الجذري أو تعديل المسارات في الكود.

كيفية الاستخدام (تشغيل سريع)
-----------------------------
1. تفعيل البيئة:
   source venv/bin/activate

2. تشغيل البرنامج الرئيسي:
   python3 main.py

3. أوامر صوتية افتراضية (التي يفحصها البرنامج بعد تحويل الصوت إلى نص بالأحرف الكبيرة):
   - "NUMBER ONE"  → كشف الأشياء
   - "NUMBER TWO"  → كشف الألوان
   - "NUMBER THREE"→ تعرف الوجوه
   - "NUMBER FOUR" → OCR وقراءة النص
   - "TIME"        → نطق الوقت الحالي
   - "VOICE"       → تسجيل ملاحظة صوتية (حفظ في recording0.wav)
   - "OPEN "       → تشغيل ملف التسجيل recording0.wav
   - "CLOSE"       → إيقاف البرنامج

ملاحظة: من المستحسن تعديل أوامر الصوت لتتناسب مع العربية إذا تم تدريب نموذج Vosk أو استخدام نموذج يدعم العربية.

المتغيرات والتهيئات
-------------------
لا يوجد ملف `.env` مخصص لكن توجد متغيرات داخل الملفات:
- ad.py: MODEL_PATH (المسار إلى نموذج Vosk)، SAMPLE_RATE، TIMEOUT_LIMIT
- color_reg.py: SOUNDS (مسارات ملفات WAV للألوان)
- object.py / facere.py / ocr_red.py: أسماء ملفات الإخراج مثل object.mp3 أو time.mp3
- تأكد من أن المسارات للكاميرا والنماذج وصلاحيات الملفات صحيحة على النظام

هيكل المشروع (مختصر)
--------------------
- ad.py                         — تحويل الكلام إلى نص (Vosk + PyAudio)
- main.py                       — الحلقة الرئيسية التي تُمكّن التفاعل الصوتي
- object.py                     — كشف الأشياء (OpenCV DNN) ونطق الأسماء
- color_reg.py                  — كشف الألوان وإخراج صوتي
- facere.py                     — تعرف الوجوه ونطق الأسماء
- ocr_red.py                    — التقاط الصور وقراءة النصوص بالعربية
- rec.py                        — تسجيل وتشغيل الصوت
- time_1.py                     — نطق الوقت الحالي
- coco.names                    — أسماء فئات COCO
- frozen_inference_graph.pb     — أوزان نموذج الكشف
- ssd_mobilenet_v3...pbtxt      — تكوين نموذج الكشف
- model.rar                     — أرشيف نموذج Vosk (فكّه إلى model/)
- img/                          — صور معروفة للتعرف على الوجوه
- sounds/                       — ملفات WAV الخاصة بالألوان

نصائح تشغيلية
--------------
- استبدل gTTS بـ espeak أو pyttsx3 إذا أردت نطقًا محليًا بدون إنترنت.
- تقليل حجم إطار الإدخال في كشف الأشياء (setInputSize) يحسّن الأداء على Raspberry Pi.
- ضع النماذج الكبيرة خارج المستودع (Git LFS أو روابط تحميل في Releases) لتقليل حجم الريبو.
- اجعل أوامر الصوت بالعربية إذا استخدمت نموذج Vosk يدعم العربية.
